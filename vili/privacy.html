Vili Family – Privacy policy

Last updated: 3 October 2026

Vili Family is a private application used only by Jaroslav Povolný and his household. It is not offered to the public.

What data it accesses

  • Google Calendar: calendars and events of the signed-in account, to list, create, update and delete events on the owner's request.
  • Google Photos: media items of the signed-in account, read-only.

How the data is used and stored

  • Data is used only to answer the owner's own requests.
  • OAuth tokens and any fetched data are stored only on the owner's private computer.
  • Data is not sold, shared with third parties, used for advertising, or used to train AI models.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
